# Redactions

Before publishing, every text file in this repository (including the Lean check output in [`lean/logs/`](lean/logs/) and the Python logs in [`scripts/logs/`](scripts/logs/)) was scanned on 2026-11-27 for local user paths, the machine's hostname and e-mail addresses.

- **Lean check output.** [`lean/logs/axioms.log`](lean/logs/axioms.log), [`lean/logs/axioms_standalone.log`](lean/logs/axioms_standalone.log) and [`lean/logs/lean_check_standalone.log`](lean/logs/lean_check_standalone.log) contain no local path, hostname or e-mail address, so nothing had to be replaced. Paths in them are relative (for example `Pipeline\QueensSpectrum\Defs.lean`). Had any been present, they would have been replaced by `<user>` and `<host>`. The files are otherwise exactly as written by the tools.
- **Kernel replays** (added 2026-11-27, after paper version 2). The records in [`lean/kernel-replays/`](lean/kernel-replays/) were redacted where they were written: the local user directory is replaced by `<user>`, the hostname by `<host>`, and the session's temporary folder by `<scratchpad>` (in `independent/`). A scan of the copied files on 2026-11-27 found no user name, hostname or e-mail address. What remains: `standalone_build.log` (line 16) shows the full path of a temporary build folder below `<user>`, which contains session identifiers but no personal data; three logs show the folder name of the local working copy below `<user>`; and the copied READMEs refer to paths of the working repository (`<repo>/targets/queens-spectrum/…`, explained in [`LEAN.md`](LEAN.md)). The files are otherwise exactly as written.
- **Not included.** The full `build.log` of the Lean build (about 0.9 MB of import notices and linter warnings) and the LaTeX build log are not included. The last 20 lines of the build are in `lean_check_standalone.log`.
- **Appended line.** The last line of `lean_check_standalone.log`, `exit=0 seconds=97`, was added by the shell wrapper that ran the check (exit code and wall-clock time). It is not output of the check script.
- The only personal name in the repository is the author's, on the title page of the paper.
